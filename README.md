# epstein-profile

Пайплайн для разбора **личности** Джеффри Эпштейна (когнитивный стиль, установки, образ жизни, практики, кибернетическая модель его системы влияния) по публичным материалам «файлов Эпштейна». Цель — не список знакомых, а модель того, *как он думал и как была устроена его жизнь*.

## Принципы
- **Только публичные данные.** Используются тексты, уже распознанные сообществом (OCR) и выложенные на Hugging Face.
- **Приватность.** Имена всех, кто не является публичной фигурой (персонал, частные лица, любые возможные пострадавшие), заменяются псевдонимами `[P-0xx]`. Почта, телефоны и адреса удаляются. Сообщения, затрагивающие насилие, никогда не экспортируются дословно: только агрегированные счётчики.
- **Гипотезы, а не диагнозы.** Психологические выводы — модели по косвенным данным, а не клиническая оценка.
- **Прослеживаемость.** Каждый элемент несёт ID исходного документа (`EFTA…`, `HOUSE_OVERSIGHT_…`).
- **Данные не коммитятся.** В git лежит только код; `data/` в `.gitignore`.

## Стадии
```
scripts/01_build_corpus.py   # скачать (~650 МБ), разобрать письма, атрибутировать автора, дедуплицировать
scripts/02_analyze.py        # метрики без LLM + пакеты доказательств для качественного анализа
```
Стадия 3 (качественный разбор пакетов) и стадия 4 (итоговый отчёт) выполняются моделью по готовым пакетам; бюджет на API не нужен.

### Что считает стадия 2
- **Стилометрия в духе LIWC** (`stylometry.py`): местоимения я/мы/ты, уверенность и оговорки, аффект, мотивы (власть, достижение, вознаграждение, принадлежность), временная ориентация, повелительные формы, вопросы. Rates считаются на объединённом тексте группы (год и т. п.), потому что отдельные письма слишком коротки. Сравнение «он против его корреспондентов» и характерные слова по log-odds (Monroe et al., 2008).
- **Темы** (`config/themes.yaml`): 12 линз плюс чувствительная категория (только агрегированно).
- **Ритмы**: распределение по часам и дням, ночная доля, burstiness (Goh & Barabási), дневная нагрузка.
- **Коммуникационная система** (`behavior.py`): доля тредов, начатых им, взаимность, концентрация (Джини), ограничение Бёрта и эффективный размер эго-сети (брокерство), явные акты знакомства людей, латентность ответов в обе стороны.

## Запуск
```bash
pip install -r requirements.txt && python -m spacy download en_core_web_sm
python scripts/01_build_corpus.py --raw data/raw --out data/out      # ~10 мин, ~2 ГБ RAM
python scripts/02_analyze.py --out data/out                          # ~10 мин
```

## Известные ограничения
- Шум OCR; часть писем дублируется в разных производствах (двухступенчатая дедупликация).
- В редких DOJ-документах в тело его ответа попадает чужой текст: такие случаи (>300 слов) помечены `suspect_mixed`.
- Часть писем «от него» могла быть написана ассистентами с его аккаунта.
- Время писем указано так, как напечатано в источнике; часовой пояс часто неизвестен.
- Корпус — это то, что сохранилось и было опубликовано, а не вся жизнь.
